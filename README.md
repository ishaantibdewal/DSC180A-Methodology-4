# DSC 180A Methodology Assignment 4

**Page: [ishaantibdewal.github.io/DSC180A-Methodology-4](https://ishaantibdewal.github.io/DSC180A-Methodology-4/)**

Quarter 2 capstone brainstorming for DSC 180A (Data Science Capstone) at UC San Diego. Building on our
Quarter 1 project, which categorizes bank-transaction memos, it proposes using predicted spending
categories to forecast financial distress such as overdrafts (logistic regression vs. XGBoost), plus
changes to labeling and evaluation (inter-annotator agreement, an account-level holdout).
